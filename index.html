Why one-time + monthly?

Setup = migration + training. Monthly = VPS, security patches, Scout leads, updates. Without monthly we'd charge RM2k+ upfront and leave you alone — hybrid is cheaper and you stay updated.

Device limit?

MAX 5 devices — single WAHA noweb-arm :3000, 1 QR per session (slug ^[a-z0-9_-]{1,20}$). Starter cap 2, Pro cap 5 — enough for sales + admin + owner. Need 10? We can raise on Pro.

WhatsApp — official API or not?

We use WAHA WhatsApp Web automation (scan QR, mirrors whatsapp.com) — NOT the Official WhatsApp Business API. Why: no per-conversation fee (official = RM0.15–0.30/24h), setup 10 min. Risk: WhatsApp can temp-block spam (>30 new chats/hour). We mitigate: warm-up ≤10/day (3 days), queue with retry, backup 2 numbers, anti-dupe 85%. Need green-tick? We migrate to Official API later — extra Meta/BSP fees apply.
